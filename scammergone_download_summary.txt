## 🚀 Quick Start Instructions

### **1. Download All Files**
Save all 8 files above into a folder called `scammergone-bot`

### **2. Install Dependencies**
```bash
cd scammergone-bot
npm install
```

### **3. Configure Bot**
```bash
npm run setup
```
- Enter Discord Bot Token
- Enter Client ID
- Get invite link

### **4. Start Bot**
```bash
npm start
```

### **5. Use in Discord**
```bash
/scammergone status    # Check bot status
/scammergone config    # Configure settings
/settings logchannel #alerts    # Set log channel
```
