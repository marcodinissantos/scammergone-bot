## 📄 FILE: docker-compose.yml

```yaml
version: '3.8'

services:
  scammergone:
    build: .
    container_name: scammergone-bot
    restart: unless-stopped
    
    environment:
      - NODE_ENV=production
      - TZ=America/New_York
    
    env_file:
      - .env
    
    volumes:
      - ./guild_configs.json:/app/guild_configs.json
      - ./learning_data.json:/app/learning_data.json
      - ./logs:/app/logs
    
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "5"
    
    deploy:
      resources:
        limits:
          memory: 512M
        reservations:
          memory: 256M
```

## 🚀 Quick Installation

### **Prerequisites**
- Node.js 16.9.0 or higher
- Discord account with server admin permissions

### **1. Clone Repository**
```bash
git clone https://github.com/your-username/scammergone-bot.git
cd scammergone-bot
```

### **2. Install Dependencies**
```bash
npm install
```

### **3. Create Discord Bot**
1. Go to https://discord.com/developers/applications
2. Create "New Application" → Name: "ScammerGone"
3. Go to "Bot" → "Add Bot"
4. **Enable Required Intents**:
   - ✅ Message Content Intent
   - ✅ Server Members Intent
   - ✅ Presence Intent
5. Copy Bot Token and Application ID

### **4. Configure Bot**
```bash
npm run setup
```
- Enter your Discord bot token
- Enter your client ID (application ID)
- Setup creates `.env` file and provides invite link

### **5. Invite Bot to Server**
Use the invite link from setup with these permissions:
- Read Messages/View Channels ✅
- Send Messages ✅  
- Manage Messages ✅ (delete scams)
- Ban Members ✅ (ban repeat scammers)
- Use Slash Commands ✅
- Add Reactions ✅
- Embed Links ✅

### **6. Start Bot**
```bash
npm start
```

### **7. Configure in Discord**
```bash
/scammergone status          # Check bot status
/scammergone config          # Open configuration panel
/settings logchannel #alerts # Set logging channel
/channels all true           # Monitor all channels
/settings sensitivity medium # Set detection level
```

## 🧠 AI Training Guide

### **Automatic Learning**
The bot learns from admin reactions:

**Mark as Scam**: React 🙅‍♀️ to any message
- Bot learns this pattern is dangerous
- Improves future scam detection
- Adds patterns to training data

**Mark as Safe**: React ✅ to flagged message
- Bot learns this was a false positive
- Reduces similar future detections
- Improves accuracy

### **Training Tips**
- Start with **medium sensitivity** (recommended)
- Train on 10-20 examples for best results
- Include various scam types: crypto, gaming, phishing
- Mark false positives to improve accuracy
- Export training data regularly as backup

## 🔧 Troubleshooting

<details>
<summary><strong>Bot Not Responding?</strong></summary>

- ✅ Check bot is online in Discord member list
- ✅ Verify bot token in `.env` file
- ✅ Ensure bot has "Use Slash Commands" permission
- ✅ Wait 5-10 minutes for Discord to sync commands
- ✅ Check console for error messages

</details>

<details>
<summary><strong>Not Detecting Scams?</strong></summary>

- ✅ Check sensitivity: `/settings sensitivity`
- ✅ Verify monitored channels: `/channels list`
- ✅ Test detection: `/scammergone test "Free Bitcoin!"`
- ✅ Train AI with 🙅‍♀️ reactions on scam messages
- ✅ Check if user has whitelisted role

</details>

<details>
<summary><strong>High False Positives?</strong></summary>

- ✅ Lower sensitivity: `/settings sensitivity low`
- ✅ React ✅ to false positive messages
- ✅ Add users to whitelist roles
- ✅ Train AI with legitimate message examples

</details>
